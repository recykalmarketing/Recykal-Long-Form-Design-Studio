# v1.3.0 — Editorial Publishing Engine

This release upgrades Long Form Design Studio from a page-by-page AI composer into a source-faithful publishing engine inspired by professional long-form editorial systems. It learns layout principles from the supplied TOMRA and Reloop references without copying their branded artwork or proprietary page designs.

## QC findings that drove this release

The v1.2.3 Goa DRS review exposed structural and creative failures: a 17-page source selection expanded to 26 output pages; sparse/near-empty pages appeared between dense pages; TOC continuations were misclassified as article pages; random TOC entries became page titles; the glossary was rendered as a generic two-column table with broken term/definition pairing; headings were created from sentence fragments; source glyphs such as en-dashes, currency signs, and ligatures were corrupted; and long stretches of narrative repeated the same two-column composition without editorial rhythm.

## Reference-derived publishing principles

The TOMRA reference demonstrates deliberate page-role rhythm: cover, visual contents divider, clean navigation, chapter opener, narrative spread, categorical infographic, data story, and image-led transition. It uses visuals to explain structure rather than to fill empty space.

The Reloop Modern DRS Guide combines a strong conceptual cover, photo-led foreword, hierarchy-led contents, numbered practice architecture, case-study moments, pull quotes, data and explanatory text. Section identity is persistent while individual pages vary according to content purpose.

The Reloop Global Deposit Book shows how a very long reference publication can remain coherent through stable running furniture, section rails, repeatable country/profile masters, dense but readable glossary composition, maps, compact data modules, and consistent navigation.

## Publishing architecture implemented

1. Source ingestion now separates canonical text fidelity from layout geometry. Poppler `pdftotext -layout` is preferred for text fidelity while PDF.js geometry determines columns and tables. This prevents source characters such as `2–3`, `€0.25`, and `40–90` from becoming corrupted strings.
2. Embedded source images can be extracted with Poppler and reused on the source-relevant page instead of regenerating them with AI.
3. Preserve mode first builds logical stories. Consecutive TOC and glossary source pages are merged into semantic stories and repaginated according to publishing capacity rather than source-page boundaries.
4. TOC and glossary layouts are deterministic. TOCs become structured `SECTION / PAGE` navigation. Glossaries become true `TERM / DEFINITION` reference pages. Both bypass page-generation AI.
5. Page archetypes now include cover, section opener, message, TOC, glossary, editorial, editorial sidebar, two-column, stat, quote, timeline, comparison, process, table, chart, data story, case study, summary, profile, image-led and closing.
6. The renderer has purpose-built treatments for page archetypes and native semantic vector diagrams. Decorative empty side panels and generic placeholders are no longer acceptable page-filling strategies.
7. Section/chapter running headers are inferred automatically and persist through continuation pages unless a manual master header overrides them.
8. Long-form preflight checks block replacement glyphs, malformed quote markers, broken PDF ligatures, generic `COLUMN 1 / COLUMN 2` tables, sentence-fragment headings, raw dot-leader TOC text, incorrect TOC/glossary layouts and dangerously sparse ordinary pages.
9. Preserve-mode page acceptance requires source coverage and ordered-source fidelity before creative quality is considered.
10. Structural QC runs before expensive visual generation and before AI QC. A page with missing/reordered content cannot pass merely because it looks polished.

## OpenAI usage reduction

The release reduces credits by moving deterministic publishing tasks out of the model: PDF extraction, TOC reconstruction, glossary reconstruction, pagination heuristics, source coverage, ordering, preflight and native vector rendering all run locally. AI image variations default to one, source visuals are reused when available, native vector visuals are preferred for processes/data/flows, default image-generation caps are lower, and structural failures are repaired before paying for AI QC. Prompt-cache keys are versioned for the stable design-system prefix.

## Acceptance criteria

A Preserve-mode document must not silently lose, invent or reorder source content. A structural story must retain its identity across page breaks. No ordinary page may be exported with accidental extreme underfill. TOC and glossary pages must use their semantic masters. A failed or interrupted generation must resume from its durable checkpoint. A final document must pass the 90/100 QC gate, while source-fidelity blockers remain hard failures regardless of the visual score.
