# v1.2.1 - Source Fidelity & A4 Layout Fix

This release corrects a structural failure discovered with the Goa Deposit Refund Scheme handbook.

## Root causes fixed

1. Preserve-mode source allocation was keyword/chunk based, so adjacent source pages could be unevenly assigned to designed pages.
2. A heuristic character budget was allowed to abort generation even when the source page itself was readable on A4.
3. Dense message/foreword content could be collapsed into a quote layout that rendered only the quote and dropped the remaining paragraphs.
4. Exact page targets were treated as per-page hard budgets instead of publication-level targets.
5. Cover and quote fallback visuals reused a generic wave motif and could clip long titles/subtitles.
6. Layout rhythm contained a mechanical editorial/two-column alternation rule rather than a content-led decision.

## New architecture

### Deterministic source allocation in Preserve mode
- PDF/PPT source segments remain in source order.
- When target pages >= source pages, each source page gets at least one output page.
- Additional requested pages are assigned to the densest source pages first.
- Each assigned source slice is carried into page generation as an authoritative source slice.
- When target pages < source pages, adjacent source pages are grouped sequentially by content weight.

### Page-level source fidelity gate
- Generated Preserve-mode pages are checked against the exact source slice assigned to them.
- If less than 78% lexical coverage remains, the page retries.
- If AI layout retries still omit source content, a deterministic source-faithful fallback page is created instead of stopping the project.
- Whole-project Preserve-mode QC blocks Final export below 82% source coverage.

### A4 handling
- A4 stays fixed at 210 x 297 mm.
- The character-budget heuristic no longer stops generation.
- Overfull pages are marked for A4 reflow.
- With automatic page expansion enabled, only genuinely overfull designed pages create continuation pages; the effective project target updates to the real physical-page count.
- Exact hard-limit behavior remains available when automatic expansion is explicitly disabled.

### Layout safeguards
- Dense source pages cannot become quote-only layouts.
- Image-led layouts are not automatically selected for dense pages merely because an image block exists.
- Mechanical alternation between editorial and two-column pages was removed.
- Semantic background treatments no longer vary by arbitrary page-index patterns.

### PDF renderer
- Cover uses a true two-field editorial composition and adaptive title sizing.
- Cover subtitle stays inside the left content field.
- The previous large filler band and repeated wave pattern were removed.
- Quote and closing fallbacks use restrained semantic fields rather than the repeated wave motif.

## Acceptance test - Goa DRS handbook

For a 50-page selected PDF source with an 85-page Preserve-mode target:
- generation must not stop on source page 4 solely because of heuristic A4 budget;
- source page 2 leadership message must not be reduced to one pull quote;
- all assigned source text must remain represented;
- title/subtitle must not clip on the cover;
- physical pages must stay A4 portrait;
- page target may expand only when actual content reflow requires it, not because a coarse character estimate says so;
- Review PDF must remain available regardless of QC score.
