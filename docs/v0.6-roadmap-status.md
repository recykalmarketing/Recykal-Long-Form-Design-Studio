# Long Form Design Studio — Roadmap implementation status (v0.6.0)

This file tracks the professional-design roadmap proposed during product review. Gamma, Pitch, Beautiful.ai, Canva and Figma are category benchmarks only; Long Form Design Studio is a native Recykal product.

## Implemented in v0.6

### Smart layout / constraint layer
- Semantic layout inference before decoration.
- A4 6-column editorial families and modular presentation layouts.
- Density/occupancy estimation in QC; accidental under-fill and over-density are flagged.
- Content reflow uses additional pages rather than intentionally shrinking long-form body copy.
- Table rows size from content and continue across PDF pages with repeated headers.

### Project masters and global replacement
- Cover-only Recykal logo by default.
- Project-level header, footer and page numbering.
- One-click Find/Replace across the entire project while retaining layout structure.

### Visual art direction
- Recykal theme selector.
- Image source selector: AI, Recykal/source assets, mixed, placeholders or no images.
- Art-style system with Suggested / Photo / Illustration / Abstract / Custom groups.
- Custom image-style prompt.
- Up to four visual style-reference images used as a moodboard.
- 1–3 generated image alternatives per image block.
- User can switch visual settings after generation and recompose the project.

### Design alternatives
- Three page-level design directions from the same content.
- Factual claims, data and source meaning must remain unchanged between alternatives.

### Asset intelligence
- Source-file and Knowledge Hub embedded assets are indexed.
- Mixed/source-asset modes prefer existing Recykal/source visuals before generating replacements.
- Image provenance records whether an asset was uploaded, sourced or AI-generated.

### Safe replacement + smart crop
- Drag/drop or upload replacement for images without changing the frame.
- Table/chart replacement from CSV/XLS/XLSX while retaining the block slot.
- File-based text replacement keeps the block/page identity.
- AI analyses uploaded/generated images for a focal point; users can override horizontal/vertical focal points and Fit/Fill.

### Outline approval
- Optional Design Plan before full generation.
- User can edit section/slide title, layout and visual treatment before approving generation.

### Version history
- Automatic checkpoints before consequential AI actions/recomposition.
- Manual checkpoints and restore.

### Review workflow
- Draft → Content Review → Design Review → Approved status.
- Reviewer/owner field.
- Review comments.
- Approved page lock to prevent accidental element editing until explicitly unlocked.

### Multi-format semantic recomposition
- Document, Presentation and Graphic can be repurposed to another supported format.
- The AI is instructed to reprioritize content instead of proportionally resizing it.

### Accessibility and evidence controls
- Alt text for meaningful images.
- QC checks hierarchy, contrast/accessibility expectations, data integrity, source/table fidelity and production risks.
- Source provenance panel and citation/source records.

### Rendered-export preflight
- Structural validation after export: PDF page count/text presence, PPTX slide/media structure, PNG dimensions.
- Docker includes Poppler so PDF/PPTX outputs can be rasterized.
- Optional OpenAI vision pass inspects rendered pages for visible clipping, overlap, broken tables, stretched/pixelated images, accidental dead space, header/footer inconsistency, logo misuse and contrast problems.
- Critical visual preflight defects block final export; review exports remain available.

## Still intentionally future / enterprise work

These are not required to validate the core design engine, but remain valuable after design quality is proven:
- Real-time multi-user presence and threaded comments.
- SSO/SCIM and granular RBAC.
- Persistent object storage/CDN instead of Render ephemeral upload storage.
- Rights-managed/licensed stock-media provider integration.
- Automated localization QA for many language-specific typographic systems.
- Share-link analytics and engagement heatmaps.
- Public API / workflow automation hooks.
- Visual side-by-side version diff beyond restore/checkpoint history.

## Product principle

The Studio should not win by having the largest preset library. It should win by combining source fidelity, editorial reasoning, Recykal brand constraints, visual art direction, editable structure and an export quality gate in one workflow.
