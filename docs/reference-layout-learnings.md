# Reference layout learnings — v0.4

The uploaded annual report / ESG documents are treated as design references, not as content sources and not as templates to copy. Their useful structural patterns are encoded into the runtime design engine:

- Asymmetric editorial covers with strong title zones and a meaningful hero/vector field.
- Table-of-contents / orientation pages with numbered section mapping.
- Leadership pages combining portrait/visual, quote/callout and multi-column narrative.
- Dense narrative pages using a 6-column A4 grid and two readable text columns.
- Stat dashboards combining metrics, charts, icons and short interpretation.
- Timelines with visible paths/nodes, not paragraph lists.
- Process and values pages using vector connectors and semantic icons.
- Comparison pages using aligned split columns.
- Financial/data pages using accurate tables with consistent cells and repeated headers when tables continue.
- Image-led contextual pages used as rhythm changes, not filler.
- Deliberate opening/pause/closing negative space, while ordinary information pages target high meaningful occupancy.
- Page-to-page rhythm: opening → orientation → narrative → evidence → pause → synthesis → action.

Recykal brand rules override all colors, fonts, logos and decorative treatments found in the references.
