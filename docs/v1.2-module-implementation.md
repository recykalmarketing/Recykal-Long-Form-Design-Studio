# v1.2 Module-by-Module Implementation Notes

## `server/ai.mjs`
### Data model
- `block.frame` normalized into `freeform, x, y, w, h, autoHeight, z`.
- `page.surface` normalized into a semantic mode/role.
- `settings.autoExpandPageTarget` persisted.

### Layout intelligence
`inferSurfaceTreatment()` determines restrained page surfaces from semantic page role/layout. It is deterministic, not random.

### Generation resilience
`generateProjectStream()` catches `EXACT_PAGE_BUDGET` when auto expansion is enabled. It:
1. computes a larger effective target;
2. updates project settings;
3. creates a revised remaining outline anchored to completed pages;
4. emits `target-expanded`;
5. checkpoints the project;
6. retries the current page and continues.

Completed pages are not regenerated.

## `server/index.mjs`
### Generation endpoints
All generate/outline paths accept and forward `autoExpandPageTarget`.

### Export endpoint
`POST /api/projects/:id/export`
- parses `review` before QC logic;
- review exports skip mandatory AI QC;
- final exports run/require current QC and approval as configured;
- deterministic/rendered preflight still runs for review diagnostics.

## `src/main.jsx`
### Create workflow
Exact page target UI includes `Allow automatic page increase`, default ON. Streaming handler consumes `target-expanded` and updates progress/target count live.

### Recent Work
Project cards include Open, Export and Delete. Export invokes Review Digital PDF so it does not depend on QC.

### `PositionableBlock`
Wraps every canvas block. When selected:
- drag handle changes to percentage-based freeform positioning;
- resize handle changes `w/h` and switches to fixed height;
- pointer movement is previewed locally and committed on pointer-up.

### `FrameControls`
Inspector exposes:
- Flow / Free
- X / Y / Width / Height
- Auto height
- Layer controls

### Canvas surfaces
`CanvasPage` reads `page.surface` and renders semantic background layers. The old repeated page accent motif is removed.

### Export menu
Working/Review exports are always displayed above Final exports. Final options show the QC/approval reason when disabled.

## `src/styles.css`
Adds:
- project card action styling;
- freeform selection, drag and resize handles;
- inspector frame controls;
- two-column span protection for major/freeform blocks;
- semantic surface treatments using active theme variables;
- no common repeated decorative page device.

## `server/exporters.mjs`
### PDF
- semantic page surface modes are rendered into PDF backgrounds;
- free-position blocks are excluded from normal flow and drawn as overlays using their percentage frames;
- text width/height is respected without changing font scale;
- images/charts/tables/stats receive frame-aware drawing;
- normal flow, continuation pagination and table repetition remain unchanged for non-freeform blocks.

### PPTX
- semantic surfaces map to native PowerPoint shapes;
- freeform frame coordinates map to slide coordinates for text, data, tables, charts and images;
- freeform blocks do not advance the normal vertical flow;
- the old unconditional right-side arc decoration is removed.

## `server/qc.mjs`
Adds deterministic manual-frame checks:
- outside content bounds -> blocking;
- narrow long-content frame -> warning;
- likely fixed-height clipping -> blocking.

Existing typography, A4, table, hierarchy and accessibility checks remain active.

## Acceptance test matrix
1. Generate exact 20-page document with auto expansion OFF; hard-stop/recovery remains possible.
2. Generate undersized exact target with expansion ON; target grows and streaming continues.
3. Download Review PDF with no QC record.
4. Download Review PDF with failed QC.
5. Final export remains blocked at failed/stale QC.
6. Recent Work Export opens Review Digital PDF.
7. Recent Work Delete removes server + browser copy.
8. Select paragraph -> Free -> reduce width -> text reflows.
9. Drag table/image/stat -> position persists after refresh/Postgres save.
10. Export PDF -> freeform positions correspond to editor layout and remain on A4.
11. Fixed-height overflowing paragraph -> QC blocking defect.
12. Surface modes vary by page role; no automatic repeated motif on every page.
13. Manually change page surface -> save/reopen/export retains it.
14. Two-column page remains fixed A4 portrait.
15. Wide/long tables remain structured and readable in Review PDF.
