# v1.2.2 — QC Auto-Redesign & Structural Fidelity

This release hardens long-form document generation after the 56/100 Goa DRS review output.

## Changes
- Final QC threshold raised from 85/100 to 90/100.
- When QC is below 90, the studio automatically starts a page-by-page corrective redesign pass (up to 2 rounds by default) instead of stopping at a low score.
- Manual **Run QC** uses the same auto-redesign loop.
- Rendered export QA is now part of the final 90/100 gate. If rendered visual QA is below 90, visible defects are fed back into a page-by-page redesign pass and the export is retried once.
- Review/preview exports no longer place the red `DRAFT • QC REVIEW • xx/100` badge on the artwork. Review filenames use `-REVIEW` only.
- Exact page targets no longer silently expand by default. The system first recomposes inside the requested A4 page count. Auto expansion only occurs when explicitly enabled.
- Preserve-mode page generation now validates both source coverage and source reading order.
- TABLE OF CONTENTS and GLOSSARY pages are structurally prioritised so incidental entries are not promoted into random page headlines.
- Preserve-mode prompts explicitly lock reading order, term-definition pairing, TOC structure, numbered-item grouping, table cells and semantic continuity.
- Auto-redesign protects source fidelity: a prettier page is rejected if it drops or scrambles authoritative source content.

## New environment controls
- `QC_PAGE_REDESIGN_ROUNDS=2`
- `QC_PAGE_REDESIGN_MAX_PAGES=60`
- Legacy `QC_MAX_REVISIONS` is set to `0`; the page-by-page redesign loop is authoritative.
